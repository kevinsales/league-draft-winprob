How much does the draft actually decide a League game?

A calibrated win-probability model built only from champion select — ten champions and their bans, nothing else. The honest answer to the question is the finding, and the answer is: very little.

The headline

After seeing both complete drafts — all ten champions and every ban — the best model reaches ROC-AUC 0.513, just +1.3 points above a coin flip. Its accuracy of 53.8% is only +0.3 points better than blindly always guessing the more common side (53.5%). Across 1,679 games, every single prediction it made fell between 41% and 55%.

That last number is the one worth sitting with. The model is never confident, because the draft never justifies confidence.

Which champions move the needle?

Because the model is a plain logistic regression, each champion's effect can be read off directly and converted into percentage points of win chance. The champions below are the most extreme in the entire dataset — and the strongest of them shifts the game by less than two games in a hundred.

Is the model any good?

Evaluation is calibration-forward: the useful question is not "how often is it right" but "when it says 55%, does blue win 55% of the time?" Every model below was scored by nested cross-validation on identical folds — hyperparameters tuned on training rows only, so no model ever saw the games it is judged on.

Two results worth stating plainly. First, the gradient-boosted model lost to plain logistic regression; aggregating five champions into archetype counts throws away champion identity, which is where the little signal there is actually lives. Second, regularisation mattered more than model choice — an earlier version with a hand-picked penalty was beaten by a coin flip, not because it was wrong on average but because it was overconfident.

My own games

The same model applied to my recent ranked games. These matches are explicitly held out of training, so this is a genuine out-of-sample test rather than the model recalling games it had already memorised.

Limitations

  • One region, one rank band. Apex tiers on SEA (South-East Asia) only. Nothing here should be assumed to transfer to other servers or to lower ranks, where the meta and execution differ.
  • Patch scope. Restricted to 16.13 + 16.12 for a coherent meta, so the champion effects are a snapshot, not permanent truths.
  • Correlational, not causal. The model sees final compositions with no pick order, no counter-pick context, and no idea who played what. A champion's coefficient reflects who tends to pick it and into what, not the champion's intrinsic strength.
  • Archetype labels are hand-curated. The engage / enchanter / poke / hard-CC columns are a judgement call, not official data.
  • Rank labels are approximate. Match-V5 has no game-tier field, so a game's tier is inferred from the player whose history surfaced it.
  • Solo-queue variance is enormous. Ten players, connection issues, tilt and one early mistake all swamp the draft. That is precisely the finding.

So what should you take from this?

Draft matters, but not nearly as much as the discourse around it suggests. If you lost a solo-queue game, the composition on the loading screen almost certainly was not why. Blue side won 46.5% of these games, and knowing all twenty champions barely improves on that.

The rest is execution.
